# 🏦 ATM Simulator

> A console-based ATM Simulator built with Java to practice Object-Oriented Programming, JDBC, JPA/Hibernate, PostgreSQL, and software design principles.

---

## 📖 About

ATM Simulator is a personal learning project designed to simulate the core functionalities of a real Automated Teller Machine (ATM).

The main goal of this project is not only to implement banking operations but also to improve problem-solving skills, software architecture, clean code practices, and object-oriented design.

The project will gradually evolve as new technologies and concepts are learned.

---

## ✨ Features

- 🔐 User Authentication
- 💳 Bank Card Management
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Money Transfer
- 📜 Transaction History
- 💵 Account Balance
- 🔑 PIN Verification
- 🚫 Withdrawal Limits
- ⚠️ Exception Handling
- 🗄️ Database Integration
- 📊 Transaction Logging
